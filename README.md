# G6-thumb-camera-mod

Create custom sounds/images on your G6 Thumb Camera

Processor is HX3302B, flash chip is P25Q80H.

# Usage

Ensure custom sizes are less than the original file sizes


# Custom .wav
* Sample Size
* Bit
* Mono
* Fill in rest options

# Custom Boot Images
## Exporting from GIMP
* Progressive: `OFF`
* Export as CMYK: `OFF`
* Use Arithmetic Coding: `OFF`
* Optimize: `ON`
* Subsampling: `4:2:0`
* DCT method: `Integer`
